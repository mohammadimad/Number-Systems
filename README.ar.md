# محوّل الأنظمة العددية

تطبيق سطح مكتب باستخدام Windows Forms لتحويل القيم بين الأنظمة العشري والثنائي والثماني والسداسي عشري. يركز المشروع على تحويل الأسس وفحص المدخلات وأحداث النماذج وعناصر واجهة سطح المكتب التفاعلية.

## المزايا

- اختيار النظام العددي المصدر والنظام الهدف.
- التحويل بين التمثيلات العشرية والثنائية والثمانية والسداسية عشرية.
- تبديل النظامين المصدر والهدف.
- إعادة ضبط حقلي الإدخال والنتيجة.
- التحقق من أرقام النظامين الثنائي والثماني قبل التحويل.
- عرض النظامين المحددين ونتيجة التحويل داخل الواجهة.
- إغلاق التطبيق من خلال زر مخصص.

## التقنيات المستخدمة

- C#
- Windows Forms
- .NET Framework 4.7.2

## بنية المشروع

```text
Counting systems/
|-- Counting systems.sln
|-- Counting systems.csproj
|-- Program.cs             # نقطة تشغيل التطبيق
|-- Form1.cs               # منطق التحويل وأحداث الواجهة
|-- Form1.Designer.cs      # تصميم النافذة وعناصر التحكم
`-- Properties/            # الموارد والإعدادات ومعلومات التجميع
```

## البناء والتشغيل

### المتطلبات

- Windows
- Visual Studio مع حزمة **.NET desktop development**
- .NET Framework 4.7.2 Developer Pack أو بيئة بناء متوافقة

```bash
git clone https://github.com/mohammadimad/Number-Systems.git
cd Number-Systems
```

افتح `Counting systems/Counting systems.sln` في Visual Studio وشغّل المشروع، أو ابنِه من طرفية متوافقة:

```powershell
dotnet build "Counting systems/Counting systems.sln" --configuration Release
```

## التحقق من البناء

تم بناء إعداد Release محليًا بالنتيجة التالية:

```text

```

## النطاق الحالي

هذا محوّل تعليمي مخصص للأعداد الصحيحة. تحلل بعض مسارات التحويل النص الظاهر أولًا بوصفه عددًا عشريًا بدل توحيد القيمة وفق النظام المصدر المحدد، كما تحتاج مدخلات النظام السداسي عشري التي تحتوي على أحرف إلى تحليل وتحقق أقوى. ينبغي إصلاح هذه المسارات قبل اعتبار جميع التحويلات جاهزة للاستخدام الإنتاجي.

## تحسينات مقترحة

- توحيد كل عملية تحويل عبر قيمة عددية عشرية وسيطة.
- دعم أحرف النظام السداسي عشري بأمان ودون حساسية لحالة الحرف.
- استبدال `int.Parse` بتحقق لا يرمي استثناءات.
- دعم الأعداد السالبة والقيم الأكبر من `Int32`.
- منع اختيار النظام نفسه مصدرًا وهدفًا.
- إضافة النسخ إلى الحافظة وسجل التحويلات.
- إضافة Unit Tests لكل زوج من الأنظمة وللمدخلات غير الصحيحة.
